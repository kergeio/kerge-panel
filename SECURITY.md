# Security policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues, pull
requests or discussions.

Report them privately through GitHub instead: open the **Security** tab
of this repository and choose **Report a vulnerability**, or go to
<https://github.com/kergeio/kerge-panel/security/advisories/new>.

Describe what you found, how to reproduce it and which version is
affected. The discussion, the fix and its disclosure then happen in that
private report.

## Supported versions

Kerge is in pre-release. Fixes go into the next release; there are no
maintained older versions.
